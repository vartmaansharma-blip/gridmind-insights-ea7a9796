## Maintenance rules

- Treat the Decision Constitution as the current source of scope and conflict resolution.
- Keep dated audit reports as historical evidence; do not silently present their environment observations as current.
- Prefer updating an existing canonical document over creating another overlapping strategy document.
- Every new strategic decision should state the previous decision, change, evidence, trade-offs, risks, date, and affected documents.
- Label claims as observed evidence, inference, or untested hypothesis.
- Do not delete historical migration/audit records merely to make the directory shorter.
