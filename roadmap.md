# GridMind product-design roadmap — parked reference

**Status: PARKED — not the active execution queue.**  
**Authority:** The [canonical Master Plan](docs/gridmind-master-plan-2026-10-11.md) controls current execution. Customer discovery and the [technical release gate](docs/release-gate.md) take priority over broad product redesign. See [design audit issue #30](https://github.com/vartmaansharma-blip/gridmind-insights-ea7a9796/issues/30).

The checklist below is retained as a design backlog reference. Unchecked items are **not authorization to implement them now**. Do not use this file as a second roadmap or infer priority from checkbox order. Reopen an item only when a recorded decision or the Master Plan explicitly prioritizes it, and execute it through a GitHub Issue with testable acceptance criteria.

## Deferred design candidates

- [ ] Unify product shell, brand, navigation, factory context, analysis status, and demo labeling
- [ ] Reframe overview around economic exposure, opportunities, evidence, actions, performance, capacity, reliability, and verification
- [ ] Make opportunities the primary evidence-to-action workflow with five V1 classes and honest uncertainty
- [ ] Upgrade machine register and passport as the supporting legacy-integration evidence layer
- [ ] Rework savings into a baseline-to-verification workflow with potential versus realized value
- [ ] Align energy, alerts, and factory/data screens with shared terminology and empty/error states
- [ ] Complete route metadata, build, runtime, desktop, and mobile verification

## Re-entry conditions

1. Recheck the current Master Plan and technical release gate.
2. Confirm the workflow is justified by customer/problem evidence or is necessary to resolve a critical correctness/security defect.
3. Create or update the governing GitHub Issue with scope, non-goals, dependencies, test plan, and acceptance criteria.
4. Keep synthetic/demo data, persisted customer data, estimated exposure, potential value, and verified outcomes visibly distinct.
5. Validate accessibility, reduced motion, responsive behaviour, and the exact deployed build where applicable.

Design work alone does not establish customer validation, industrial accuracy, or production readiness.
